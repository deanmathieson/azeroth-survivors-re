      Play It Yourself

      Installation takes longer than a Molten Core trash pull. Barely.

      You need World of Warcraft 1.12.1 client data to play. Nothing Blizzard-owned is hosted here or in the repo. Step 3 fetches a client's Data folder for you.

      1. 1

        Gather your reagents

        Install Rust from rustup.rs, plus Git.

      2. 2

        Pick up the quest

        Clone the code.

        git clone -b progression https://github.com/deanmathieson/azeroth-survivors-re
      3. 3

        Fetch the game data

        The repo ships no Blizzard files. This script downloads a WoW 1.12.1 client's Data folder (about 5.5 GB) into wow-data/. On Windows, run it from Git Bash. Good time to put the kettle on.

        cd azeroth-survivors-re && bash scripts/fetch-data.sh
      4. 4

        Hearth in

        Build and play. The first build takes about ten minutes, which is exactly long enough to argue about who's tanking.

        PowerShell

        $env:WOW_DATA="$PWD\wow-data\Data"; cargo survivors

        macOS, Linux or Git Bash

        WOW_DATA=wow-data/Data cargo survivors
