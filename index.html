Azeroth Survivors

A Megabonk-style survivors game set in vanilla Azeroth. Pick a class, walk into a zone, and hold off the horde for fifteen minutes while your spells cast themselves and a boss shows up every couple of minutes.

Where it's at

Playable, freshly built

  • 358 tests pass, clippy is clean, and the play build is good to go on progression.
  • WoW-style camera is in: right-drag mouselook, scroll zoom, V for the old top-down view, and proper tree and doodad collision.
  • Death results are fast: Enter restarts the same hero, zone and options; Esc or the button returns to the main menu.
  • Positional, throttled WoW cast and impact sounds are joined by level-up, coin, chest and boss cues; every battleground now has music and ambience, with the login theme crossfading on the menu.
  • Bosses have a top-centre WoW frame, skull, health %, final-boss tag and 1.5× roster size. Wooden caches, iron-bound paid chests and golden, minimap-marked ornate boss chests now tier up; the final boss gets the grandest, with loot rolled on opening and a Loot: item banner.
  • Equipped gear visibly changes your hero. Appearance customisation and a hero name carry through to the Character panel and results screen.
  • Rings, trinkets and necklaces can appear in-run or at quest turn-ins; C opens equipped jewelry and the full stat breakdown.
  • Legendary skill upgrades now use real special mechanics: procs, echoes, novas and more.
  • Companion 2.0 fetches drops, levels, and unlocks critter looks through pet level, achievements, quests and the Faire.
  • Field quest givers now offer accept, complete and turn-in loops: a cache worth of gold, a jewelry choice and bonus XP.
  • The Darkmoon Faire's gacha-style Prize Booth spends in-game tickets only—never real money—on companion looks: Silver Tabby, Bombay, Cornish Rex, Senegal, Cockatiel, owls, Tree Frog, Crimson Snake, whelplings, Pet Bombling, Lil' Smoky, Smolderweb Hatchling and Disgusting Oozeling. A Collection tab tracks the 15 classic vanity pets.
  • Talent states are honest: green when learnable, grey with the reason when points run out, gold at max; all 51 points are reachable.
  • Save format v4 is live, with older saves migrated forward.
  • Expect rough edges and balance that needs tuning.

Run it yourself

  1. Install Rust from rustup.rs, plus Git.

  2. Get the code on the progression branch.

    git clone -b progression https://github.com/deanmathieson/azeroth-survivors-re

  3. Get the game data. The repo ships no Blizzard files; this script downloads a WoW 1.12.1 client's Data folder (about 5.5 GB) into wow-data/. On Windows, run it from Git Bash.

    cd azeroth-survivors-re && bash scripts/fetch-data.sh

  4. Build and play. The first build takes about ten minutes.

    PowerShell
    $env:WOW_DATA="$PWD\wow-data\Data"; cargo survivors
    macOS, Linux or Git Bash
    WOW_DATA=wow-data/Data cargo survivors
