# Controls

**Azeroth Survivors** — WoW's own camera and movement by default; **V** swaps to the classic
top-down view, one hand on WASD and the other on the wheel.

| When | Key / Input | Action |
|---|---|---|
| Menu | Click a race, gender, class and zone | make your pick (**Randomize** rolls one) |
| Menu | **Enter** (or **Enter World**) | start the run; the world travels to the zone picked |
| Playing | **W / S** or **↑ / ↓** | WoW view: run forward / backpedal along your facing |
| Playing | **A / D** or **← / →** | WoW view: turn; with the right mouse button held, strafe |
| Playing | **Q / E** | WoW view: strafe left / right |
| Playing | **right-drag** | WoW view: mouselook, turning the hero with the camera |
| Playing | **left-drag** | WoW view: swing the camera around the hero without turning him |
| Playing | **both mouse buttons** | WoW view: run forward, steering with the mouse |
| Playing | **W / S / A / D** or **arrow keys** | classic view: move the hero (he faces the cursor, backpedals and strafes) |
| Playing | **Space** | jump |
| Playing | **F** (from level 5) | your class's movement spell: in the WoW view Blink goes forward and Charge takes the nearest enemy ahead; in the classic view they aim at the cursor |
| Any | **V** | swap the WoW camera and the classic top-down view (remembered) |
| Any | **G** | toggle the picture polish (`?grade=0` starts it off) |
| Playing | **mouse wheel** | zoom: WoW view out to `cameraDistanceMax` (15 yd by default); classic view from over the shoulder out to 70 yd |
| Playing | **Esc** | pause |
| Playing | — | abilities cast themselves (no aim) |
| Level up | **1 / 2 / 3** (or click a card) | pick an upgrade |
| Level up | **R** (or **Reroll**) | deal a new hand (2 a run) |
| Level up | **B** (or **Banish**), then a card | strike that choice for the rest of the run and deal its slot again (1 a run; **B** again cancels) |
| Level up | **Skip** | pass the hand up for gold |
| Paused | **Esc** | resume |
| Game over | **Enter** (or **Play again**) | back to the menu |
| Any | minimap **+ / −** / minimize | minimap zoom / collapse |

The camera is WoW's: it sits behind the hero, swings back behind him as he runs, and stops short
of walls and terrain. **V** swaps to the classic view (locked top-down, laptop-friendly, the hero
facing the cursor) and back; the choice is remembered across launches. Either way the hero walks
into trees, rocks and buildings rather than through them. In the menu the camera slowly orbits
the preview hero. Your race, gender, class and zone are remembered across reloads.
